# Chat Application 

A real-time chat application built with **Vanilla JavaScript**, **Node.js**, and **Express**. The project demonstrates how clients receive real-time updates using **regular polling** and **long polling**, while allowing users to send messages and react with likes or dislikes.

## Features

- 💬 Send and receive messages
- 👍 Like and 👎 dislike messages
- 🔄 Switch between regular polling and long polling
- 🛡️ Client and server-side input validation
- 🔒 Safe rendering using `textContent`

## Tech Stack

- HTML
- CSS
- JavaScript (ES6)
- Node.js
- Express
- CORS

## Running the Project

### Backend

```bash
git clone https://github.com/JanefrancessC/Module-Decomposition.git
cd Module-Decomposition/backend
npm install
npm start
```

### Frontend

Open `frontend/index.html` in your browser, or serve it with a local development server such as Live Server.
